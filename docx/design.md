# 光影艺术展 · 设计文档

## 项目概述

单页 React 图片画廊应用，支持多个视觉主题切换。每个主题为同一套功能（文件夹选择、图片画廊、详情展示、模态框）提供不同的视觉氛围。

当前已完成的主题：

| 主题 | 风格 | 核心视觉 |
|------|------|----------|
| 森林光影 | 复古森系暗调画廊 | 金色光束、粒子、玻璃拟态 |
| 赛博博物馆 | 琥珀/青蓝数字暗房 | 扫描线、Dither、霓虹光晕 |
| 暗夜星座 | 深空星图 | Canvas 星空、SVG 星座连线 |
| 漫影剧场 | 动漫/二次元霓虹 | 樱花飘落、满月、霓虹粉蓝 |

## 新主题提案：红白蓝 · 动漫纯色色块

### 设计目标

打造一个以**红、白、蓝**为主色，强调**纯色色块拼接**与**动漫平面感**的新专题页面。视觉上参考动漫主视觉、漫画分镜、几何抽象海报的混合风格。

### 核心配色

- **红**：`#E63946` 或 `#FF2E63`（高饱和动漫红）
- **蓝**：`#1D3557` 或 `#0066FF`（深海/电光蓝）
- **白**：`#FFFFFF` 或 `#F8F9FA`（作为呼吸空间与高光）
- **黑**：`#111111`（描边、文字、网格线）

### 视觉元素

- 大块几何色块（矩形、梯形、三角）斜向拼接
- 粗黑描边让元素"跳"出画面
- 白色高光/反光增强平面动漫感
- 漫画对话框、星星、感叹号、集中线等装饰
- 网点纸阴影（ manga screentone ）
- 图片像漫画分镜一样带边框

## 候选设计风格

### 方案 A：蒙德里安几何（Mondrian）

**关键词**：粗黑线网格、原色块、绝对平面、秩序感

- 背景是白色/浅灰画布
- 用粗黑线把画面切成不规则矩形网格
- 色块填充红、蓝、白，少量黑线
- 图片卡片像挂在画廊墙上的画作，hover 时色块轻微位移
- 文字用无衬线粗体，像展览标签

**适合**：干净、艺术画廊感、高级感

---

### 方案 B：孟菲斯风格（Memphis）

**关键词**：80s/90s、波浪、圆点、三角、高饱和、playful

- 红/蓝/白背景上叠加不规则几何图形
- 黑色描边、斑马纹/水波纹、小圆点装饰
- 按钮是圆角大色块，带阴影
- 字体可以粗圆体，像卡通片头
- 动效：弹性缩放、旋转、弹跳

**适合**：活泼、复古、潮流、年轻感

---

### 方案 C：动漫主视觉 / ACG UI

**关键词**：色块分割、速度线、对话框、高光、二次元

- 背景用大块斜向分割：红、白、蓝三个大三角/梯形
- 加入动漫元素：对话框、星星、感叹号、集中线
- 图片卡片像漫画分镜，有描边和网点阴影
- 强调色红+蓝，白色作呼吸空间
- 动效：快速切分、闪白、像动画转场

**适合**：最贴合"动漫纯色和色块"描述

---

### 方案 D：包豪斯/国际主义（Bauhaus / Swiss）

**关键词**：功能主义、几何、Helvetica、网格、海报感

- 严格网格系统
- 红/蓝/白大色块 + 黑色无衬线文字
- 不对称布局，像电影海报
- 图片以矩形/圆形框架呈现
- 动效克制：滑动、淡入、对齐

**适合**：海报感、设计杂志、冷静有力

---

## 推荐方案

**首选方案 C（动漫主视觉 / ACG UI）**，因为它最贴合"红白蓝 + 动漫纯色 + 色块拼接"的核心诉求。

可以进一步 hybrid：
- 蒙德里安的秩序（网格与色块比例）
- 动漫的速度线/集中线/对话框装饰
- 孟菲斯的活泼弹性动效

## 动效方向

### A. 色块拼贴式入场

- 页面加载时，红/白/蓝三色块像拼图一样从四周或斜角滑入，拼出完整背景
- 图片卡片像被"贴"到墙上，带轻微弹跳（back.out）
- 切换图片时，当前画面被色块覆盖后新画面出现

### B. 漫画分镜式转场

- 斜向色块像漫画分镜线一样划过屏幕
- 点击/hover 时出现集中线（speed lines）或星星闪光
- 文字像漫画拟声词一样弹出

### C. 故障艺术 + 色块错位

- 红/蓝/白三色轻微错位（RGB split）1-2 像素
- hover 时色块抖动/偏移
- 像老式 TV 信号不良的动漫 OP 感

### D. 几何抽象律动

- 色块缓慢呼吸缩放，像 living poster
- 网格线轻微变形
- 图片在圆形/三角形/矩形框架间切换
